# EEG-Controlled Robotic Arm

This project enables control of a robotic arm using brainwave signals and eye blinks from the NeuroSky MindWave EEG headset.  
EEG signals are processed in Python and sent via Serial to an Arduino Uno for real-time robotic arm movement.

## 🧩 Features
- Real-time EEG data acquisition from NeuroSky MindWave
- Signal processing and feature extraction in Python
- Machine learning classification for movement commands
- Serial communication with Arduino Uno
- Multi-DOF robotic arm movement control
- Real-time GUI for EEG visualization

## 🧠 Technologies Used
- Python (NumPy, Pandas, Scikit-learn, Matplotlib)
- Arduino IDE (C/C++)
- NeuroSky MindWave Mobile II EEG Headset
- 5 DOF Robotic Arm

## ⚙️ Future Work
- Improve EEG classification accuracy (target: 70–80%)
- Integrate deep learning for better movement recognition
- Add vision system (Interaction Guided Mode) for hand gestures control
